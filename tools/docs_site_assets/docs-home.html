{{ primary_cards_raw }}

Git-first database development

Keep schemas, migrations, safeguards, and settings in reviewable source trees with the rest of the application.

Shorter migrations

Migrate persistent data schemas explicitly, then recreate function and API schemas from source instead of maintaining long migration files for them.

Reviewable SQL output

Generate SQL from source trees and pseudo-hosts for CI artifacts, pull request review, or DBA-controlled execution.

Guarded upgrades

Use stored revisions, migration path checks, safeguard scripts, and ACL checks to catch unsafe states before final commit.

Application-owned roles

Run technical SQL through configured source-tree roles instead of depending on the default postgres role where privileges allow it.

Single or multi-host runs

Operate on one database for a focused release, or resolve a multi-host setup and run the same source tree across a fleet.

Targeted settings

Override conninfo or host params for a single-host run, and feed settings SQL with shared deployment values for each environment.
